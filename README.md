# GameHub

A collaborative gaming platform designed and developed as a university team project. GameHub serves as a centralized, desktop-optimized interface for gaming enthusiasts to explore and engage with gaming content.

## Features
*   **Immersive Gaming UI:** An engaging layout specifically tailored for desktop gamers.
*   **Modular Architecture:** Developed as a team-led effort, integrating clean and organized code components.
*   **Interactive Interface:** Features smooth navigation and dynamic elements using JavaScript.

## Tech Stack
*   **Frontend:** HTML5, CSS3, JavaScript
*   **Deployment:** GitHub Pages
